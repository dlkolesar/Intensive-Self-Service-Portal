API Documentation

-All API documentation should be written using the Open API Specification 3.0(https://swagger.io/specification/)
-all docs should be in the json format



Directory Structure

+--Category1
+----API 1 Name
+------xxxxx.json (required)
+------xxxxx.png,xxxxx.jpg,xxxxx.gif, OR xxxxx.ico (optional)
+----API 2 Name
+------xxxxx.json (required)
+------xxxxx.png,xxxxx.jpg,xxxxx.gif, OR xxxxx.ico (optional)

+------xxxxx.json (required)
